# Конструктор JSON/XML

Браузерное мини-приложение для проектирования структур обмена данными.

Возможности:

- создание JSON и XML по таблице атрибутов;
- генерация JSON Schema и XSD;
- импорт структуры из Excel с выбором колонок;
- перевод русских названий полей в `snake_case` или `Snake_Case`;
- настройка типов, длины и числовой точности;
- UML-диаграммы полного маршрута запроса и ответа;
- настройка отправителя, интерфейсов, брокера, получателя и обратного пути;
- экспорт диаграмм в PlantUML;
- локальная работа без отправки пользовательских данных на сервер.

## Запуск

Скачайте репозиторий и откройте `index.html` в актуальном Chrome или Edge. Сервер и установка зависимостей не требуются.

Готовый архив находится в файле `Конструктор-сообщений.zip`.

## Исходники

- `web/index.html` — разметка приложения;
- `web/style.css` — оформление и адаптивная компоновка;
- `web/core.js` — модели JSON/XML и генераторы схем;
- `web/app.js` — интерфейс, Excel и UML;
- `examples` — примеры Excel, JSON, XML, JSON Schema и XSD.

## Ограничения

Автоматический перевод использует встроенный словарь предметных терминов. Неизвестные слова транслитерируются, после чего имя можно изменить вручную. Поддерживается до 5000 строк за импорт и файлы Excel размером до 20 МБ.
