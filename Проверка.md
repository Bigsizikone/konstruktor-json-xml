# Проверка результата

## Браузер

Проверен автономный запуск через `file://` в Chrome, без сервера. Книга Excel считывается встроенной библиотекой, поэтому интернет для импорта не нужен.

Автоматическая проверка охватывает:

- выбор Excel-файла и листа;
- автоматическое определение колонок наименования, типа и длины;
- переключение `snake_case` / `Snake_Case`;
- перевод распространённых русских терминов и транслитерацию неизвестных;
- разбор строковой длины и числовой разрядности `15,2`;
- загрузку атрибутов в таблицу;
- генерацию JSON и JSON Schema с `x-source-name`;
- сохранение и повторное открытие проекта;
- JSON, XML, JSON Schema, XSD и UML/PlantUML с прямым и обратным маршрутами;
- ошибки длины, разрядности, даты и потери точности числа.

Пример `examples/attributes.xlsx` содержит строки, числа, целое и дату. В тесте из него формируются `order_number`, `order_amount`, `order_date`, `product_quantity` и `unknown_field`; для суммы проверяются 15 цифр и 2 знака после запятой.

## Визуальная проверка

Диалог импорта просмотрен в браузере: поля сопоставления, предварительный просмотр и результат проверки строк помещаются без наложений. На узких экранах настройки располагаются вертикально, а широкая таблица предварительного просмотра прокручивается внутри диалога.

Основной интерфейс и UML проверены в светлой и тёмной теме, а также на мобильной ширине. На широком экране запрос и ответ расположены двумя встречными рядами, а на телефоне маршрут превращается в читаемую вертикальную цепочку. Страница не выходит за ширину окна.

## Ограничения

Автоматический перевод работает по встроенному словарю предметных терминов. Слова, которых нет в словаре, транслитерируются; полученное имя можно изменить после импорта. Первая непустая строка листа считается строкой заголовков. За один импорт обрабатывается до 5000 атрибутов, размер файла ограничен 20 МБ.
